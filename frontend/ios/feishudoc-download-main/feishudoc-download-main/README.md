# 飞书文档下载器（Feishu Document Downloader）

一款适用于 **Chrome** 和 **Edge** 浏览器的扩展插件，能够自动检测飞书在线文档预览页面，并将文档全页内容导出为 PDF 文件下载到本地。

---

## ✨ 功能特性

- **自动检测**：打开飞书文档预览页面后，插件自动拦截渲染接口并激活下载入口，无需手动操作。
- **悬浮按钮**：在页面右下角注入一个可拖动的蓝色悬浮按钮，随时可将其拖到不遮挡内容的位置。
- **双模式下载**：鼠标悬浮在按钮上弹出两种下载方式：
  - **图片型（原模式）**：将每页渲染后的 WebP 截图按顺序合并为 PDF 静默下载，速度快，适合快速留档。
  - **文字型（新模式）**：在图片底层叠加透明的精准坐标文字层，通过系统打印引擎生成双层 PDF，**文字可被鼠标选中和复制**。
- **进度反馈**：下载过程中按钮实时显示当前进度（如"正在获取第 3/11 页…"），处理完成后提示下载成功。
- **智能文件命名**：优先读取网页 `og:title` 元数据获取精确文件名，降级时自动清理标题中多余的下划线和"飞书云文档"后缀。

## 📁 项目结构

```
FeishuDoc/
├── manifest.json        # 扩展描述文件（Manifest V3）
├── background.js        # 后台 Service Worker，负责拦截目标网络请求

├── jspdf.umd.min.js     # 第三方 PDF 生成库（jsPDF v2.5.1，本地化引入）

```

## 🔧 安装方法

> 本插件为本地开发版本，需通过浏览器"开发者模式"手动加载，无需上架扩展商店。

### Chrome 浏览器

1. 在地址栏输入 `chrome://extensions/` 并回车。
2. 打开右上角的 **开发者模式（Developer mode）** 开关。
3. 点击左上角的 **加载已解压的扩展程序（Load unpacked）**。
4. 在弹出的文件浏览器中选择本项目目录（`FeishuDoc` 文件夹）。
5. 扩展列表中出现 **Feishu Document Downloader** 即表示安装成功。

### Edge 浏览器

1. 在地址栏输入 `edge://extensions/` 并回车。
2. 打开左侧菜单底部的 **开发者模式** 开关。
3. 点击 **加载已解压的扩展程序**，选择本项目目录。
4. 完成安装。

## 🚀 使用方法

1. 在浏览器中打开一篇飞书在线文档预览页面，例如：
   ```
   https://*****.feishu.cn/file/PDZcbC8awowxovxc7tIcyxyznzF
   ```
2. 等待页面完全加载后，页面右下角会自动出现蓝色的 **「下载 PDF」** 悬浮按钮。
3. 鼠标**悬浮**在按钮上，弹出两个下载选项：
   - 点击 **图片型（原模式）**：插件静默拉取所有页面的 WebP 图片并合并，直接触发浏览器下载。
   - 点击 **文字型（新模式）**：插件精细拼装每页的图片底层与透明文本层，完成后弹出系统打印对话框，在弹窗中保存为 PDF 即可。
4. 按钮可以在页面内任意拖动，避免遮挡文档内容。

## ⚙️ 技术原理

| 技术点 | 说明 |
|---|---|
| 网络请求拦截 | `background.js` 使用 `chrome.webRequest.onCompleted` 监听 `txt_all.json` 接口 |
| 页面结构解析 | `txt_all.json` 包含每页所有文字的精确坐标（`r`）、字号（`h`）、内容（`t`）字段 |
| 图片获取 | 逐页请求 `img_0.webp`, `img_1.webp`… 并转换为 Base64 |
| 图片型 PDF | 使用 `jsPDF` 将所有 WebP 页面打包成纯图像 PDF |
| 文字型 PDF | 在隐藏 `iframe` 中将 WebP 图作底图，按坐标叠加透明文本层，借用浏览器打印引擎生成可选字 PDF |
| 防止拦截循环 | 所有由插件自身发起的 fetch 请求均附带 `&_ext=1` 参数，`background.js` 对此放行 |

---

## 🗒️ 注意事项

- 本插件仅适用于飞书文档"**预览流**"格式的页面（URL 特征为 `/file/` 或通过 `/preview_sub/` 接口加载的文档）。
- 图片型导出的 PDF 内文字为图像，**不支持文本选中和搜索**。
- 文字型导出使用系统打印功能，弹窗中请选择 **"另存为 PDF"** 而非实体打印机。
- 如页面插件未能自动激活（即未出现下载按钮），可尝试**刷新页面**后再等待几秒。
